## 🚀 Getting Started

### First Time Setup (Onboarding)

When you first open the app, you'll go through a smart onboarding process:

#### Step 1: Primary Goals
- **Search** for your main career goal (e.g., "Data Analyst", "Frontend Developer")
- Type to search - no fixed lists!
- Can add custom goals if not found
- Select your primary career goal

#### Step 2: Secondary Goals (Optional)
- Add part-time or secondary career interests
- Example: "Age Care Worker", "Customer Service"
- Perfect for students with diverse interests
- Skip if you only have one goal

#### Step 3: Experience Level
- Choose: Beginner, Intermediate, or Advanced
- This helps personalize your learning path
- Be honest - it's okay to be a beginner!

#### Step 4: Time Commitment
- How many hours per week can you dedicate?
- Options: 5, 10, 20, or 40+ hours
- Affects roadmap pacing and recommendations

#### Step 5: Current Skills
- **Search** and add skills you already have
- Type to search (e.g., "JavaScript", "Python", "Communication")
- Add as many as you want
- Can add custom skills

#### Step 6: Learning Style
- Visual: Prefer videos and diagrams
- Hands-on: Learn by doing projects
- Reading: Prefer articles and documentation
- Mixed: Combination of all styles

#### Step 7: Upload Documents (Optional)
- Upload your **resume** (PDF or TXT)
- Upload existing **roadmap** (PDF or TXT)
- AI will analyze and provide suggestions
- Skip if you don't have documents yet

## 🔄 Data & Privacy

### Where Your Data is Stored
- **localStorage**: All user data (profile, progress, documents)
- **Your device only**: Nothing sent to external servers
- **No database**: Everything is local

### What This Means
- ✅ Your data is private
- ✅ Works offline (after first load)
- ✅ No account needed
- ⚠️ Clearing browser data = losing progress
- ⚠️ Data doesn't sync across devices

### Backing Up Your Data
To save your progress:
1. Open browser DevTools (F12)
2. Go to Application → Local Storage
3. Copy the `dream-app-state` value
4. Save it somewhere safe
5. Restore by pasting it back

## 🐛 Troubleshooting

### "No profile found" Error
- Complete onboarding first
- Check localStorage isn't disabled
- Try refreshing the page

### Progress Not Saving
- Check browser allows localStorage
- Don't use incognito/private mode
- Check browser storage isn't full

### Document Upload Fails
- Check file is PDF or TXT
- Check file is under 10MB
- Try a different file format

### AI Analysis Not Working
- This is normal without API keys
- App uses rule-based logic instead
- See `AI_SETUP_GUIDE.md` to enable AI
