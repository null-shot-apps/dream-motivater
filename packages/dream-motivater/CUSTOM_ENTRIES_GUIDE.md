# Custom Goals & Skills Guide

## 🎯 Overview

The Dream Career App now supports **unlimited custom goals and skills**! You're not limited to predefined lists - add ANY career goal or skill that matches your unique path.

## ✨ How Custom Entries Work

### Adding Custom Goals

When you search for a goal in the onboarding:

1. **Type your goal** (e.g., "Freelance Photographer", "Part-time Barista")
2. **See suggestions** from our database of 100+ career options
3. **Add custom entry** - If your exact goal isn't listed, you'll see:
   ```
   ✨ Add "Your Custom Goal" (custom)
   ```
4. **Click to add** - Your custom goal is saved and treated just like any predefined goal

### Adding Custom Skills

Same process for skills:

1. **Type your skill** (e.g., "Mandarin", "Pottery", "Video Editing")
2. **See suggestions** from our database of 200+ skills
3. **Add custom entry** - If not listed, you'll see:
   ```
   ✨ Add "Your Custom Skill" (custom)
   ```
4. **Click to add** - Your custom skill is saved

## 💡 Tips for Custom Entries

### Be Specific
- ❌ "Tech stuff"
- ✅ "Blockchain Development"

### Use Standard Terms
- ❌ "Making websites look good"
- ✅ "Frontend Development" or "UI Design"

### Multiple Related Skills
Instead of "Web Development", add:
- HTML
- CSS
- JavaScript
- React

### Combine Primary + Secondary Goals
Perfect for students with diverse interests:
- **Primary:** Data Analyst
- **Secondary:** Part-time Age Care Worker
- **Secondary:** Freelance Content Writer

## 🔧 Technical Details

### How Search Works
1. **Fuzzy matching** - Finds partial matches in the database
2. **Custom option** - Always shows if no exact match exists
3. **Smart suggestions** - Prioritizes relevant results

### Data Storage
- All custom entries saved in localStorage
- Treated identically to predefined options
- Persists across sessions
- No server required

### AI Integration
- Custom goals/skills analyzed by AI service
- Generates personalized recommendations
- Adapts learning paths accordingly
- Works with both free and paid AI APIs
